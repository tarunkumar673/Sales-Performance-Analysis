# Sales Performance Analysis

## Project Overview

This project analyzes sales data to understand business performance,
sales trends, product performance, and regional performance.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis

- Data Cleaning
- Sales KPI Analysis
- Category-wise Sales
- Monthly Sales Trend
- Top 10 Products
- Region-wise Sales
- State-wise Sales
- Discount vs Profit Analysis

## Dataset

The dataset contains 10,000 sales records.
